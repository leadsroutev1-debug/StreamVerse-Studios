# StreamVerse Studios

## Project overview

StreamVerse Studios is an autonomous content-production backend and control-room dashboard. It coordinates storyline and episode simulation, image/video generation, durable MySQL checkpoints, media processing, and publishing integrations.

The main application starts with `bash start.sh`, which launches the Python video engine and the Node.js backend. The dashboard is served on port 5000.
